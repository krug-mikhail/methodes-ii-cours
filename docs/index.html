3 Le fil conducteur du cours

Le cours suit les étapes d’un projet de recherche empirique quantitative :

  1. Identifier l’objet de recherche → question de recherche
  2. Cadre théorique et formulation des hypothèses
  3. Opérationnalisation : passer d’un concept à des indicateurs mesurables
  4. Collecte des données : choix de la source (enquête, contenu, données existantes)
  5. Préparation et codage des données
  6. Analyse descriptive (uni-/bi-/multivariée) puis inférentielle (tests, régression)
  7. Communication des résultats : qualité, transparence, réplicabilité
