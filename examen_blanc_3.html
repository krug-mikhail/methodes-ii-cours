Section A · Statistiques descriptives avancées (Q1-Q3)
Q1
Vrai ou faux ? La moyenne est plus sensible aux valeurs extrêmes (outliers) que la médiane.
  • a. Vrai
  • b. Faux
Vrai. La moyenne intègre toutes les valeurs : un outlier la « tire » dans sa direction. Pour des distributions asymétriques (revenus, prix immobiliers), on rapporte médiane + IQR plutôt que moyenne + écart-type.
Q2
Une distribution a une skewness positive (asymétrie à droite). Cela signifie que :
  • a. La queue est à gauche, moyenne < médiane
  • b. La queue est à droite, moyenne > médiane
  • c. La distribution est symétrique
  • d. Il y a beaucoup d'outliers négatifs
Skewness positive = quelques valeurs très hautes tirent la moyenne vers la droite. Ex : salaires (médiane à 5'000 CHF, moyenne à 9'000 CHF). La queue longue est du côté positif.
Q3
À quoi sert une boîte à moustaches (boxplot) ?
  • a. Visualiser la fréquence d'une variable nominale
  • b. Visualiser la distribution d'une variable numérique (médiane, quartiles, outliers)
  • c. Visualiser la relation entre 2 variables continues
  • d. Calculer une régression
Boxplot : la boîte = Q1 à Q3 (IQR) ; la ligne = médiane ; les moustaches = jusqu'à 1.5×IQR ; points isolés = outliers potentiels.
Section B · Tests d'hypothèses (Q4-Q8)
Q4
En statistique inférentielle, H₀ (hypothèse nulle) représente :
  • a. La conclusion que la recherche essaie de prouver
  • b. L'absence d'effet / de différence / de relation — l'hypothèse qu'on cherche à rejeter
  • c. Une hypothèse alternative
  • d. Le résultat le plus probable
H₀ = « il n'y a rien ». On la présume vraie ; si les données sont trop improbables sous H₀ (p < α), on la rejette pour H₁. On ne « prouve » jamais H₀.
Q5
Une erreur de type I consiste à :
  • a. Ne pas rejeter H₀ alors qu'elle est fausse
  • b. Rejeter H₀ alors qu'elle est vraie (faux positif)
  • c. Choisir le mauvais test
  • d. Avoir un échantillon trop petit
Type I = faux positif (rejet à tort). Probabilité = α (souvent 0.05). Type II = faux négatif (ne pas rejeter alors que H₀ est fausse). Probabilité = β.
Q6
Si la p-value = 0.03 et le seuil α = 0.05, on :
  • a. Rejette H₀ : le résultat est significatif
  • b. Ne rejette pas H₀
  • c. Conclut que H₀ a 3% de chances d'être vraie
  • d. Le test est invalide
p = 0.03 < α = 0.05 → on rejette H₀. ⚠️ Piège : la p-value n'est PAS la probabilité que H₀ soit vraie — c'est la probabilité d'observer des données aussi extrêmes sous H₀.
Q7
Pour comparer la moyenne de 2 groupes sur une variable continue (ex. temps Instagram femmes vs hommes), on utilise :
  • a. Test du chi²
  • b. Test t de Student
  • c. ANOVA
  • d. Régression logistique
Test t = différence de moyenne entre 2 groupes. ANOVA = 3+ groupes. Chi² = 2 nominales. Corrélation = 2 continues.
Q8
Un test du chi² permet de tester :
  • a. La différence entre deux moyennes
  • b. L'indépendance / l'association entre deux variables catégorielles
  • c. La force d'une corrélation
  • d. La normalité d'une distribution
Chi² = test pour 2 variables catégorielles. Ex : « le genre est-il associé au choix d'études ? » → tableau croisé → test χ². H₀ : indépendance ; H₁ : association.
Section C · Régression linéaire (Q9-Q14)
Q9
Dans lm(Y ~ X1 + X2 + X3), le coefficient de X1 s'interprète comme :
  • a. L'effet brut de X1 sur Y
  • b. L'effet de X1 sur Y, X2 et X3 étant maintenus constants (ceteris paribus)
  • c. La corrélation entre X1 et Y
  • d. La probabilité que X1 influence Y
« Toutes choses égales par ailleurs ». La force de la régression multiple = isoler l'effet de chaque variable en contrôlant les autres.
Q10
Vrai ou faux ? Un R² élevé garantit que le modèle est causalement correct.
  • a. Vrai
  • b. Faux
Faux. R² = part de variance expliquée, pas une preuve de causalité. Ex : ventes de glaces ↔ noyades = R² élevé, mais c'est la chaleur (variable cachée). Pour la causalité : design expérimental, contrôle des variables omises.
Q11
Quelle est la différence entre R² et R² ajusté ?
  • a. Aucune différence
  • b. R² ajusté est toujours plus grand
  • c. R² ajusté pénalise l'ajout de variables non informatives ; utile pour comparer des modèles à nombre de prédicteurs différent
  • d. R² ajusté est utilisé pour la régression logistique
Le R² augmente toujours avec plus de variables. Le R² ajusté pénalise chaque variable ajoutée. Si R² ajusté baisse après ajout → la variable n'apporte rien.
Q12
Une variable dummy (variable indicatrice) sert à :
  • a. Indiquer une valeur manquante
  • b. Coder une variable catégorielle (k catégories → k-1 dummies)
  • c. Tester la normalité
  • d. Remplacer une variable continue
Ex : genre (F/H/Autre) → 2 dummies (est_femme, est_autre). La catégorie omise (H) = référence. Les coefs s'interprètent par rapport à cette référence.
Q13
Dans un tableau de régression, le coefficient de la variable « Heures Instagram/jour » est b = +0.35, p < .001 (Y = score de dépression). Quelle interprétation ?
  • a. Chaque heure d'Instagram augmente la dépression de 35%
  • b. Chaque heure d'Instagram augmente le score de dépression de 0.35 point, ceteris paribus
  • c. L'effet n'est pas significatif
  • d. L'effet est très petit donc négligeable
b = +0.35 = chaque heure de plus → +0.35 point, toutes choses égales par ailleurs. p < .001 = très significatif (mais ne dit rien sur la taille). Pour un score sur 10, +0.35 par heure est substantiel.
Q14
Si deux variables prédictives sont fortement corrélées entre elles dans une régression multiple, on parle de :
  • a. Hétéroscédasticité
  • b. Multicolinéarité
  • c. Surajustement
  • d. Endogénéité
Multicolinéarité : coefficients instables, SE gonflées, p-values trop élevées. Solutions : enlever une des variables, créer un indice composite, utiliser une PCA.
Section D · Qualité et communication (Q15-Q21)
Q15
Vrai ou faux ? La réplicabilité signifie obtenir les mêmes résultats en réutilisant les mêmes données et le même code.
  • a. Vrai
  • b. Faux
Faux. C'est la reproductibilité computationnelle (mêmes données + code → mêmes résultats). La réplicabilité est plus exigeante : refaire une nouvelle étude (nouvel échantillon) et obtenir des résultats cohérents.
Q16
Qu'est-ce qu'un pré-enregistrement (preregistration) ?
  • a. Une inscription préalable à l'examen
  • b. Le dépôt public, AVANT collecte des données, du plan complet de recherche (hypothèses, méthodes, analyses)
  • c. Un test pilote
  • d. Une demande d'autorisation éthique
Le pré-enregistrement évite : HARKing (inventer les hypothèses après les résultats), p-hacking (multiplier les tests), cherry-picking (ne reporter que ce qui marche). Plateformes : OSF, AsPredicted.
Q17
Le principe FAIR pour la gestion des données scientifiques signifie :
  • a. Fast, Accurate, Indexed, Reliable
  • b. Findable, Accessible, Interoperable, Reusable
  • c. Free, Authorized, Independent, Responsible
  • d. Funded, Approved, Investigated, Reproduced
FAIR = standard pour les données ouvertes : Findable (avec métadonnées), Accessible (via un identifiant pérenne), Interoperable (formats ouverts), Reusable (licence claire).
Q18
Mauvaise pratique graphique : un diagramme en bâtons montre les ventes de janvier (96) à juin (99). L'axe Y commence à 95 et finit à 100, faisant croire à une explosion des ventes. Le problème est :
  • a. Mauvais choix de couleur
  • b. Axe Y tronqué — l'écart visuel est exagéré par rapport à la différence réelle (3-4% seulement)
  • c. Pas assez de données
  • d. Légende manquante
Règle d'or : pour un diagramme en bâtons, l'axe Y commence à 0 (sauf justification explicite). Un axe tronqué distord la perception de l'amplitude.
Q19
Comment cite-t-on correctement un test t (style APA) ?
  • a. « t était grande, p était petite »
  • b. « le test est significatif »
  • c. « les groupes diffèrent, t(45) = 3.12, p < .001 »
  • d. « t = 3.12 et p = 0.0008 »
Format APA : statistique en italique, ddl entre parenthèses, p en valeurs < (pas d'égalité pour les très petits p). Toujours ajouter une taille d'effet (d de Cohen, η²).
Q20
Quand on rapporte une moyenne dans un texte scientifique, on l'accompagne typiquement de :
  • a. La p-value
  • b. L'écart-type (SD) et la taille de l'échantillon (n)
  • c. La valeur min et max
  • d. La couleur du graphique
Format APA standard : « M = 3.76, SD = 0.68, n = 142, sur une échelle de 1 à 5. »
Q21
Vrai ou faux ? Un résultat non significatif (p > 0.05) prouve qu'il n'y a pas d'effet.
  • a. Vrai
  • b. Faux
Faux. Non significatif ≠ pas d'effet. Cela peut signifier : (1) effet inexistant, (2) effet existant mais échantillon trop petit (manque de puissance), (3) effet noyé dans la variance, (4) mesure imprécise. Pour conclure à l'équivalence : tests dédiés (TOST, Bayes factor).
Section E · Transversal — synthèse examen (Q22-Q25)
Q22
Place les étapes d'un projet de recherche dans le bon ordre.
  • a. Identification de l'objet → Question → Méthode → Données → Analyse → Communication
  • b. Question → Identification → Données → Analyse → Méthode → Communication
  • c. Données → Analyse → Question → Méthode → Communication → Objet
  • d. Méthode → Objet → Question → Données → Communication → Analyse
L'ordre canonique du cours (Bonneville et al., 2007) : Objet → Question → Méthode (opérationnalisation) → Collecte → Analyse → Dissémination. Étape 2bis (parfois) : formulation des hypothèses.
Q23
Pour étudier « L'influence du télétravail sur la satisfaction professionnelle des employés suisses », le type de QR est :
  • a. Descriptive
  • b. Inférentielle
  • c. Qualitative
  • d. Exploratoire
Inférentielle = on cherche à savoir si X (télétravail) influence Y (satisfaction). Descriptive = juste décrire un phénomène. Ici la formule magique « X influence Y » indique inférentiel.
Q24
Tu interroges les passants devant un magasin bio à Genève, un samedi matin, sur leurs habitudes alimentaires. Tu obtiens 80% de « oui » à « Mangez-vous sainement ? ». Principal problème ?
  • a. La taille de l'échantillon
  • b. La désirabilité sociale uniquement
  • c. Trois problèmes cumulés : biais de sélection (clientèle bio), désirabilité sociale, et formulation vague de la question
  • d. Le lieu est suffisamment représentatif
3 erreurs cumulées : (1) Sélection = les gens devant un magasin bio sont déjà sensibilisés, échantillon non représentatif. (2) Désirabilité sociale = « manger sainement » est socialement valorisé. (3) Question vague sur attitude. Solutions : panel aléatoire, anonymat, questions sur comportements précis.
Q25
Face à une question d'examen sur la régression, la structure de réponse en 3 paragraphes est :
  • a. Variables → Calculs → Conclusion
  • b. Qualité globale du modèle (R²) → Facteurs significatifs avec interprétation → Limites & critique (causalité)
  • c. Hypothèses → Méthode → Discussion
  • d. Description du tableau → Recopie des chiffres → Avis personnel
Structure gagnante en 3 paragraphes : (1) R² = qualité globale ; (2) chaque facteur significatif avec sens, taille, p, interprétation ceteris paribus ; (3) limites = corrélation ≠ causalité, variables omises, généralisabilité. Mentionner aussi les non-significatifs = pas de preuve, pas absence d'effet.
